Go с нуля
до первого проекта

Пошаговый учебник по языку Go: от установки до горутин, интерфейсов и рабочего мини-проекта. С разбором синтаксиса, живыми примерами, которые можно запускать прямо здесь, и заданиями для практики.

18 разделов код запускается в браузере задания с решениями для начинающих
00

Что такое Go и почему он такой

Go (он же Golang) — язык программирования, который создали в Google в 2009 году. Задача была прикладная: писать большие серверные программы так, чтобы код оставался простым, быстро собирался и легко работал с тысячами задач одновременно.

🔧

Go — это мебель IKEA с одним ключом

Инструментов в языке нарочно немного, и они простые. Но из этого небольшого набора собирается почти что угодно. Меньше деталей в голове — меньше способов ошибиться, легче читать чужой код.

Три вещи, которые стоит знать про характер Go с самого начала:

⚙

Компилируемый

Твой код заранее переводится в один готовый исполняемый файл. Он запускается быстро и не требует ничего доустанавливать на целевой машине.

🎯

Строго типизированный

У каждого значения есть тип. Нельзя случайно сложить число со строкой — компилятор поймает это до запуска, а не когда программой уже пользуются.

⚡

Заточен под многозадачность

Умение делать тысячи дел одновременно (горутины) встроено прямо в язык. Это его главная суперсила — до неё дойдём в разделе 13.

◆

Философия «меньше — значит лучше»

Создатели сознательно не добавляли модные возможности, если без них можно обойтись. Отсюда фирменная черта: в Go часто есть ровно один очевидный способ сделать что-то. Это скучно — и в этом вся сила: код предсказуем, потому что его читают в сто раз чаще, чем пишут.

На Go написаны Docker и Kubernetes — фундамент, на котором держится современная облачная инфраструктура. Если ты хочешь писать быстрые сервисы, сетевые утилиты или инструменты командной строки — это очень удачный выбор языка.

01

Установка и первый запуск

Чтобы писать на Go на своём компьютере, нужен сам Go — набор из компилятора и инструментов. Но чтобы попробовать язык прямо сейчас, устанавливать ничего не нужно: примеры в этом учебнике запускаются кнопкой.

Вариант A — попробовать без установки

Прямо на этой странице у примеров кода есть кнопка ▶ Запустить. Код уходит на официальный сервер Go, компилируется и возвращает результат. Идеально, чтобы пощупать язык, ничего не ставя. Есть и официальная песочница — go.dev/play.

Вариант B — поставить Go к себе

Когда захочешь писать всерьёз — скачай установщик с go.dev/dl под свою систему (Windows, macOS, Linux) и пройди мастер установки. Проверить, что всё встало, можно одной командой в терминале:

терминал 
# проверяем, что Go установлен, и смотрим версию
go version
# → go version go1.23.0 darwin/arm64  (цифры могут отличаться)

Как устроен проект на Go

Программа на Go живёт в модуле. Создать его — три команды. Не пугайся, разберём каждую в разделе 14, а пока просто общая картина:

терминал 
mkdir myapp && cd myapp   # создали папку и вошли в неё
go mod init myapp        # завели модуль — появится файл go.mod
# ...пишем код в файле main.go...
go run .                 # собрать и сразу запустить
go build                 # собрать готовый исполняемый файл
✓

Что запомнить из этого раздела

go run . — запустить проект сразу, go build — собрать готовую программу-файл. Для учёбы по этой странице достаточно кнопки «Запустить» под примерами.

02

Первая программа

Традиция — заставить компьютер поздороваться. Нажми «Запустить» под кодом и увидишь результат. Потом разберём каждую строчку.

hello.go 
package main

import "fmt"

func main() {
    fmt.Println("Привет, мир!")
}

Разберём построчно, что здесь написано:

📦

package main

Объявляет пакет. Имя main — особое: так помечается запускаемая программа. Другие имена — это библиотеки для переиспользования.

🔌

import "fmt"

Подключает пакет fmt из стандартной библиотеки — он умеет форматировать и печатать текст. Готовый инструмент, не пишем печать сами.

▶

func main()

Функция с именем main — точка входа. Программа стартует отсюда. Всё в фигурных скобках выполняется по порядку сверху вниз.

Обрати внимание: Println с большой буквы. В Go это не случайность — имя с большой буквы означает «доступно снаружи пакета» (экспортировано). С этим правилом встретимся ещё не раз.

✎ задание 1

Измени текст в кавычках на своё имя и запусти снова. Затем добавь вторую строку fmt.Println(...) с любым текстом — программа напечатает обе.

Показать решение
solution.go 
package main

import "fmt"

func main() {
    fmt.Println("Меня зовут Алекс")
    fmt.Println("Я учу Go")
}
03

Переменные и типы

Переменная — это подписанная коробка, в которой лежит значение. В Go у каждой коробки есть тип: она знает, что именно в ней хранится — число, строка или что-то ещё.

Три способа объявить переменную

vars.go 
package main

import "fmt"

func main() {
    // 1. полная форма: имя, тип, значение
    var age int = 25

    // 2. без типа — Go сам догадается по значению
    var name = "Алекс"

    // 3. короткая форма := (только внутри функций) — так пишут чаще всего
    city := "Москва"

    fmt.Println(name, "из", city, "—", age, "лет")
}

Оператор := — самый популярный в Go. Он одновременно создаёт переменную и кладёт в неё значение, выводя тип автоматически. Работает только внутри функций.

Основные типы

ТипЧто хранитПример
intцелые числа42, -7, 0
float64дробные числа3.14, -0.5
stringтекст"привет"
boolда / нетtrue, false
byteодин байт (0–255)65
runeодин символ Unicode'Я', 'a'

Константы и нулевые значения

Если значение не должно меняться — это константа, объявляется через const. А если объявить переменную без значения, Go положит туда нулевое значение: 0 для чисел, "" (пустая строка) для строк, false для булевых. В Go нет «мусора» в неинициализированных переменных — всегда предсказуемый ноль.

const.go 
package main

import "fmt"

const pi = 3.14159   // не изменить после объявления

func main() {
    var count int       // значение не задали → будет 0
    var label string    // → пустая строка ""
    var ready bool      // → false

    fmt.Println(pi, count, label, ready)
    // → 3.14159 0  false
}
⚠

Go не терпит лишнего

Объявил переменную и не использовал — программа не соберётся. То же с ненужным import. Поначалу раздражает, но так в коде не копится забытый хлам. Если переменная временно не нужна, её имя заменяют на _ (нижнее подчёркивание).

04

Операторы

Операторы — это действия над значениями: сложить, сравнить, объединить условия. В Go они привычные и без сюрпризов.

ГруппаОператорыЧто делают
Арифметика+   -   *   /   %сложить, вычесть, умножить, делить, остаток
Сравнение==   !=   <   >   <=   >=равно, не равно, меньше, больше…
Логика&&   ||   !И, ИЛИ, НЕ
Присваивание=   +=   -=   *=   /=задать, прибавить-и-задать…
operators.go 
package main

import "fmt"

func main() {
    a, b := 17, 5

    fmt.Println("сумма:", a+b)        // 22
    fmt.Println("остаток:", a%b)      // 2  (17 = 5*3 + 2)
    fmt.Println("больше ли:", a > b)   // true

    // строки объединяются тем же плюсом
    hello := "Go" + "lang"
    fmt.Println(hello)               // Golang

    // += прибавляет к тому, что уже есть
    score := 10
    score += 5
    fmt.Println("счёт:", score)      // 15
}
⚠

Целочисленное деление — частая ловушка

7 / 2 для целых чисел даст 3, а не 3.5 — дробная часть отбрасывается. Чтобы получить 3.5, хотя бы одно число должно быть дробным: 7.0 / 2.

05

Условия: if / switch

Условие — это развилка. «Если выполнилось — делаем одно, иначе — другое». В Go у if есть приятная особенность: скобки вокруг условия не нужны, а фигурные — обязательны.

if.go 
package main

import "fmt"

func main() {
    temp := 18

    if temp > 25 {
        fmt.Println("жарко")
    } else if temp >= 15 {
        fmt.Println("комфортно")
    } else {
        fmt.Println("прохладно")
    }
}

if с «коротким» объявлением

Очень характерный для Go приём: можно объявить переменную прямо в if, и она будет жить только внутри этой развилки. Часто так проверяют результат вместе с ошибкой (об этом — раздел 12).

if-short.go 
package main

import "fmt"

func main() {
    // n живёт только внутри if/else
    if n := 42 % 2; n == 0 {
        fmt.Println("чётное")
    } else {
        fmt.Println("нечётное, остаток", n)
    }
}

switch — когда веток много

Если развилок несколько, вместо лесенки if-else удобнее switch. В Go он умнее, чем в других языках: не проваливается в следующую ветку сам (не нужен break), и в case можно писать условия.

switch.go 
package main

import "fmt"

func main() {
    day := 6

    switch day {
    case 6, 7:
        fmt.Println("выходной")
    default:
        fmt.Println("рабочий день")
    }

    // switch без значения = красивая замена длинному if-else
    score := 78
    switch {
    case score >= 90:
        fmt.Println("отлично")
    case score >= 60:
        fmt.Println("неплохо")
    default:
        fmt.Println("надо подтянуть")
    }
}
06

Циклы: только for

Здесь Go доводит идею «меньше — лучше» до предела: в языке один-единственный цикл — for. Но он умеет прикидываться всеми остальными. Никаких while и do-while — всё это делает for.

for.go 
package main

import "fmt"

func main() {
    // 1. классический счётчик: старт; условие; шаг
    for i := 1; i <= 3; i++ {
        fmt.Println("шаг", i)
    }

    // 2. как while — только условие
    n := 3
    for n > 0 {
        fmt.Println("осталось", n)
        n--
    }

    // 3. бесконечный — с выходом через break
    count := 0
    for {
        count++
        if count == 2 {
            break // выходим из цикла
        }
    }
    fmt.Println("вышли на", count)
}

range — пройтись по коллекции

Чтобы перебрать список элементов, используют for ... range. Он выдаёт сразу две вещи: индекс (порядковый номер) и значение. Если индекс не нужен — заменяем его на _.

range.go 
package main

import "fmt"

func main() {
    fruits := []string{"яблоко", "груша", "слива"}

    for i, fruit := range fruits {
        fmt.Println(i, "→", fruit)
    }

    // индекс не нужен — заменяем на _
    total := 0
    for _, price := range []int{100, 250, 80} {
        total += price
    }
    fmt.Println("итого:", total)
}
✎ задание 2

Напиши цикл, который печатает числа от 1 до 10, но вместо чисел, делящихся на 3, печатает слово «Go». Подсказка: пригодится оператор остатка %.

Показать решение
solution.go 
package main

import "fmt"

func main() {
    for i := 1; i <= 10; i++ {
        if i%3 == 0 {
            fmt.Println("Go")
        } else {
            fmt.Println(i)
        }
    }
}
07

Функции

Функция — это именованный кусок кода, который можно вызывать сколько угодно раз. Даёшь ей входные данные (аргументы) — получаешь результат. В Go есть одна редкая приятность: функция может вернуть несколько значений сразу.

functions.go 
package main

import "fmt"

// принимает два int, возвращает один int
func add(a int, b int) int {
    return a + b
}

// возвращает СРАЗУ ДВА значения: частное и остаток
func divmod(a, b int) (int, int) {
    return a / b, a % b
}

func main() {
    fmt.Println(add(3, 4))        // 7

    q, r := divmod(17, 5)      // забираем оба результата
    fmt.Println("частное", q, "остаток", r) // 3, 2
}

Когда несколько аргументов подряд одного типа, тип можно указать один раз: func divmod(a, b int) вместо a int, b int.

Именованные результаты и несколько возвратов

Результатам можно дать имена — тогда return без аргументов вернёт их текущие значения. Часто так возвращают пару «значение и ошибка».

named.go 
package main

import "fmt"

// area и perimeter — именованные результаты
func rect(w, h int) (area int, perimeter int) {
    area = w * h
    perimeter = 2 * (w + h)
    return // вернёт area и perimeter
}

func main() {
    a, p := rect(4, 3)
    fmt.Println("площадь", a, "периметр", p)
}
✓

Функции — «граждане первого класса»

Функцию в Go можно положить в переменную, передать в другую функцию как аргумент и вернуть из функции. Это открывает дверь к гибким приёмам — но на старте достаточно уметь объявлять и вызывать.

08

Срезы и карты

Пока мы хранили по одному значению в переменной. Но чаще нужно хранить наборы: список покупок, таблицу цен. Для этого в Go два главных инструмента — срезы и карты.

slice — список, который умеет расти

📋

Срез — это список дел на бумажке

Элементы идут по порядку, у каждого есть номер (индекс), нумерация с нуля. В любой момент можно дописать пункт в конец. Это самая ходовая структура данных в Go.

slices.go 
package main

import "fmt"

func main() {
    nums := []int{10, 20, 30}

    fmt.Println(nums[0])       // 10 — первый элемент (счёт с нуля!)
    fmt.Println(len(nums))     // 3 — сколько элементов

    // append дописывает в конец и возвращает новый срез
    nums = append(nums, 40)
    fmt.Println(nums)          // [10 20 30 40]

    // срез среза: элементы с 1-го по 3-й (3-й не включая)
    fmt.Println(nums[1:3])     // [20 30]
}

Индексация с нуля: первый элемент — nums[0], а не nums[1]. Это стандарт почти всех языков, но новичков сбивает. len() говорит длину, append() добавляет.

map — словарь «ключ → значение»

📖

Карта — это телефонная книжка

Ищешь не по номеру строки, а по имени: «дай телефон Ани». Каждому ключу соответствует значение. Порядок не гарантирован — карта заточена под мгновенный поиск по ключу.

maps.go 
package main

import "fmt"

func main() {
    // ключи-строки, значения-числа
    prices := map[string]int{
        "хлеб":  40,
        "молоко": 80,
    }

    fmt.Println(prices["молоко"])  // 80

    prices["сыр"] = 300          // добавили пару

    // проверка «есть ли ключ»: второе значение ok
    price, ok := prices["масло"]
    if !ok {
        fmt.Println("масла нет в списке")
    } else {
        fmt.Println("масло:", price)
    }
}
✓

Приём «comma ok»

Запись value, ok := m[key] — фирменный способ Go спросить «есть ли такой ключ?». ok будет true, если ключ найден. Без него отсутствующий ключ просто вернёт нулевое значение, и не отличишь «ноль» от «нет ключа».

09

Структуры

Срез хранит однотипные элементы. Но что, если нужно описать один сложный объект — например, пользователя с именем, возрастом и городом? Для этого есть структура: свой составной тип из нескольких полей.

🪪

Структура — это анкета

Ты заранее описываешь, какие поля в анкете есть (имя, возраст, город) и какого они типа. Потом заполняешь сколько угодно таких анкет — каждая со своими данными, но по одному шаблону.

structs.go 
package main

import "fmt"

// описываем шаблон: какие поля и какого типа
type User struct {
    Name string
    Age  int
    City string
}

func main() {
    // создаём экземпляр, заполняя поля по именам
    u := User{Name: "Аня", Age: 28, City: "Казань"}

    fmt.Println(u.Name)   // доступ к полю через точку → Аня
    u.Age = 29            // поля можно менять
    fmt.Println(u)        // {Аня 29 Казань}
}

Поля с большой буквы (Name, Age) видны из других пакетов, с маленькой — только внутри своего. То же правило экспорта, что и у функций.

10

Методы и интерфейсы

В Go нет классов, как в других языках. Вместо этого — структуры с методами (функциями, привязанными к типу) и интерфейсы (описание того, что тип умеет). Это сердце того, как в Go организуют код.

Метод — функция, привязанная к типу

Метод пишется почти как функция, только перед именем в скобках указывают получателя — тип, к которому метод относится. Дальше метод вызывается через точку, как поле.

methods.go 
package main

import "fmt"

type Rectangle struct {
    Width, Height int
}

// метод Area у типа Rectangle. (r Rectangle) — получатель
func (r Rectangle) Area() int {
    return r.Width * r.Height
}

func main() {
    r := Rectangle{Width: 4, Height: 3}
    fmt.Println("площадь:", r.Area()) // 12
}

Интерфейс — «умею делать то-то»

🔌

Интерфейс — это розетка

Розетке всё равно, что ты воткнёшь — чайник, лампу или зарядку. Ей важно одно: у вилки есть нужные штырьки. Интерфейс описывает какие методы должен иметь тип. Любой тип с этими методами автоматически «подходит» — объявлять это явно не нужно.

interfaces.go 
package main

import "fmt"

// интерфейс: «любой, у кого есть метод Sound() string»
type Animal interface {
    Sound() string
}

type Dog struct{}
func (d Dog) Sound() string { return "Гав" }

type Cat struct{}
func (c Cat) Sound() string { return "Мяу" }

// функция принимает ЛЮБОГО, кто подходит под Animal
func describe(a Animal) {
    fmt.Println("звук:", a.Sound())
}

func main() {
    describe(Dog{}) // звук: Гав
    describe(Cat{}) // звук: Мяу
}
◆

«Утиная типизация» по-госвски

Если нечто крякает как утка — это утка. Dog нигде не пишет «я реализую Animal» — Go сам видит, что у него есть метод Sound(), и считает его подходящим. Это делает код гибким и слабосвязанным: типы и интерфейсы не привязаны друг к другу жёстко.

11

Указатели

Тема, которая пугает новичков зря. Указатель — это просто адрес, где лежит значение, а не само значение. Нужен он, когда хочешь, чтобы функция меняла оригинал, а не его копию.

🏠

Указатель — это адрес дома, а не сам дом

Можно дать другу копию своего дома (значение) — он поменяет копию, твой дом цел. А можно дать адрес (указатель) — тогда друг придёт и поменяет именно твой дом. По умолчанию Go передаёт в функции копии; указатель нужен, чтобы дотянуться до оригинала.

pointers.go 
package main

import "fmt"

// принимает КОПИЮ — оригинал не изменится
func addCopy(x int) { x = x + 100 }

// принимает АДРЕС (*int) — меняет оригинал
func addReal(x *int) { *x = *x + 100 }

func main() {
    n := 5

    addCopy(n)         // работала с копией
    fmt.Println(n)     // 5 — не изменилось

    addReal(&n)        // &n — «адрес переменной n»
    fmt.Println(n)     // 105 — изменилось!
}

Два значка, и всё встаёт на места: &n — «взять адрес переменной n», *x — «пойти по адресу и взять значение». Больше про указатели на старте знать не нужно.

✓

Хорошая новость про память

В отличие от C, в Go нет ручного управления памятью и «висячих указателей». За очисткой следит встроенный сборщик мусора (garbage collector). Указатели тут — только про «менять оригинал», а не про опасное жонглирование памятью.

12

Обработка ошибок

У Go узнаваемый стиль работы с ошибками. Многие языки «выбрасывают» ошибку куда-то вверх (исключения). Go делает иначе: функция возвращает ошибку как обычное значение, а ты проверяешь её прямо на месте.

📋

Ошибка — это записка вместе с результатом

Рискованная функция отдаёт две вещи: результат и записку об ошибке. Как курьер: «вот посылка, а вот бумажка — всё ли ок». Ты обязан заглянуть в бумажку, прежде чем радоваться посылке. Если ошибки нет — в записке лежит nil (пусто).

errors.go 
package main

import (
    "errors"
    "fmt"
)

// возвращает результат И ошибку
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, errors.New("деление на ноль")
    }
    return a / b, nil // nil = ошибки нет
}

func main() {
    result, err := divide(10, 2)
    if err != nil {                 // сразу проверяем записку
        fmt.Println("ошибка:", err)
        return
    }
    fmt.Println("результат:", result) // 5

    // а теперь с делением на ноль
    _, err = divide(10, 0)
    if err != nil {
        fmt.Println("ошибка:", err) // ошибка: деление на ноль
    }
}

Связка if err != nil { ... } встречается в Go-коде повсюду. Кто-то ворчит, что это многословно. Но плюс огромен: ни одна ошибка не проскользнёт незамеченной — с каждой ты разбираешься там, где она возникла, а не ловишь непонятный сбой где-то далеко.

⚠

panic — крайняя мера, не замена ошибкам

В Go есть panic — аварийная остановка программы. Но это не способ обрабатывать обычные ошибки. Паника — для ситуаций «дальше жить нельзя, всё сломано». Обычные, ожидаемые проблемы (файла нет, число не распарсилось) возвращают error, а не паникуют.

13

Горутины и каналы

Вот и главная суперсила Go. Представь повара. Обычный код — готовит по очереди: суп, потом салат, потом десерт. Go — ставит суп вариться, тут же режет салат, а десерт уже в духовке. Всё разом.

Обычный подход — одно за другим:

повар
суп
салат
десерт

Подход Go — три дела параллельно, втрое быстрее:

горутина 1
суп 🍲
горутина 2
салат 🥗
горутина 3
десерт 🍰

Горутина — помощник по слову go

Чтобы запустить параллельного «помощника», достаточно написать go перед вызовом функции. Всё волшебство. Но есть нюанс: программа не станет ждать помощников сама — нужно её попросить.

goroutines.go 
package main

import (
    "fmt"
    "time"
)

func cook(dish string) {
    fmt.Println("готовлю:", dish)
}

func main() {
    go cook("суп")     // запустили помощника и пошли дальше
    go cook("салат")   // ещё один
    go cook("десерт")  // и третий

    // даём помощникам время доделать (упрощённо)
    time.Sleep(100 * time.Millisecond)
    fmt.Println("кухня закрывается")
}

Порядок строк «готовлю: ...» может меняться от запуска к запуску — помощники работают независимо. Это нормально и есть суть параллельности.

Канал — окошко выдачи между горутинами

📮

Канал — это конвейер выдачи заказов

Чтобы горутины обменивались данными без путаницы, есть канал. Один кладёт значение в канал стрелкой ch <- x, другой забирает x := <-ch. Если забирать нечего — горутина вежливо ждёт. Так Go синхронизирует работу без ручных блокировок.

channels.go 
package main

import "fmt"

func main() {
    // создаём канал для передачи строк
    ch := make(chan string)

    // горутина кладёт результат в канал, когда готово
    go func() {
        ch <- "готово!" // отправить в канал
    }()

    msg := <-ch          // забрать из канала (тут main ждёт)
    fmt.Println(msg)      // готово!
}
◆

Девиз конкурентности в Go

«Не общайтесь через общую память — делите память через общение». То есть вместо того чтобы горутины лезли в одну переменную и мешали друг другу, они передают данные через каналы. Горутины настолько лёгкие, что их запускают тысячами — на этом и держатся высоконагруженные серверы на Go.

14

Пакеты и модули

Реальные программы не живут в одном файле. Код разбивают на пакеты (папки со связанным кодом), а весь проект — это модуль. Разберёмся, как это устроено и как подключать чужие библиотеки.

Модуль — это весь твой проект

Один раз в начале проекта создаётся файл go.mod — паспорт модуля. Он хранит имя проекта и список зависимостей (чужих библиотек, которые ты используешь).

терминал 
go mod init github.com/me/myapp  # создать модуль
go get github.com/some/lib        # скачать и добавить чужую библиотеку
go mod tidy                       # навести порядок в зависимостях

Пакет — папка со связанным кодом

Каждый файл начинается со строки package имя. Файлы в одной папке — один пакет, они видят функции и типы друг друга без импортов. А вот код из другого пакета нужно импортировать — и видны только имена с большой буквы.

ИмяВидимостьСмысл
CalcTotalэкспортированос большой буквы → видно из других пакетов
calcTotalприватнос маленькой → только внутри своего пакета

Команда go get тянет библиотеки прямо из их git-репозиториев — отдельного «магазина пакетов» не нужно. Искать готовые библиотеки удобно на pkg.go.dev — это официальный каталог документации по всем публичным пакетам Go.

Пример: строки и числа вместе

stdlib.go 
package main

import (
    "fmt"
    "strings"
    "strconv"
)

func main() {
    text := "go,rust,python"

    // разбить строку по запятой → срез строк
    langs := strings.Split(text, ",")
    fmt.Println(langs)                 // [go rust python]
    fmt.Println("всего:", len(langs))   // всего: 3

    // строку с числом превратить в int
    n, _ := strconv.Atoi("42")
    fmt.Println(n + 8)                  // 50

    // сделать текст заглавными
    fmt.Println(strings.ToUpper("golang")) // GOLANG
}

Печать с форматированием: Printf

Когда нужно вставить значения в текст, удобен Printf с «глаголами»: %d — число, %s — строка, %v — что угодно, \n — перенос строки.

printf.go 
package main

import "fmt"

func main() {
    name := "Аня"
    age := 28

    // %s подставит строку, %d — число
    fmt.Printf("%s, %d лет\n", name, age)
    // → Аня, 28 лет
}

Мини-проект: собираем всё вместе

Пора соединить пройденное в одну живую программу. Сделаем маленький анализатор списка задач: структуры, срезы, методы, циклы, условия и форматированная печать — всё в одном месте. Запусти и поиграй с данными.

todo.go 
package main

import "fmt"

// одна задача: текст и статус выполнения
type Task struct {
    Title string
    Done  bool
}

// метод: красиво показать задачу
func (t Task) String() string {
    mark := "[ ]"
    if t.Done {
        mark = "[x]"
    }
    return fmt.Sprintf("%s %s", mark, t.Title)
}

func main() {
    // срез задач
    tasks := []Task{
        {Title: "Выучить синтаксис Go", Done: true},
        {Title: "Написать первую программу", Done: true},
        {Title: "Разобраться с горутинами", Done: false},
        {Title: "Собрать свой проект", Done: false},
    }

    done := 0
    fmt.Println("— Мои задачи —")
    for _, t := range tasks {
        fmt.Println(t) // сработает метод String()
        if t.Done {
            done++
        }
    }

    // подводим итог
    percent := done * 100 / len(tasks)
    fmt.Printf("\nГотово: %d из %d (%d%%)\n",
        done, len(tasks), percent)
}

Разбери, что здесь работает вместе: структура Task описывает задачу, метод String() красиво её печатает, срез хранит список, цикл range его обходит, условие считает выполненные, а Printf выводит итог. Это уже настоящая маленькая программа.

✎ финальное задание

Добавь в список свою задачу, помести пару из них в статус «выполнено», запусти и проверь, что процент готовности пересчитался правильно. Затем попробуй добавить метод, который считает только невыполненные задачи.

Показать подсказку

Метод на срезе не повесить напрямую, но можно написать обычную функцию func countPending(tasks []Task) int, которая проходит range-циклом и увеличивает счётчик, когда !t.Done. Вызови её в main и напечатай результат.
